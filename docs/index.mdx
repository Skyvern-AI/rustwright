Rustwright keeps the Playwright-shaped API while replacing the Node driver with a native Rust engine that speaks Chrome DevTools Protocol directly.

<Note>
Rustwright is alpha software and currently supports Chromium. Use the [parity map](/PARITY) to distinguish API presence from behavior covered by the shared test suite.
</Note>

## Architecture

```text
playwright-python:  your code --pipe--> Node driver --CDP--> Chromium
rustwright:         your code ---------------------CDP--> Chromium
```

The Rust core owns Chromium process management, browser primitives, input, events, network interception, and artifact helpers. Thin language bindings expose that engine without a separate driver subprocess.
